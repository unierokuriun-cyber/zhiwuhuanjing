# 植伴第六阶段需求与范围


| 模块 | 实际实现 | 服务边界 |
|---|---|---|
| 我的花园 | 问候、天气、植物卡片、添加/编辑/删除档案、任务、养护历史、成长分享 | 天气与环境数据为演示 |
| 智能养护 | 上传预览、候选确认建档、关联问答、个性化建议、症状观察、月/周日历 | 识别固定候选，不分析图像；规则模拟回复 |
| 植物伙伴 | 原创 SVG 分身、可解释状态、聊天、每日互动、等级、六项成就、虚拟花园 | 拟人化状态不是植物感知；无真实 AI |
| 植物社区 | 物种频道、推荐/关注、筛选排序、搜索、发帖、点赞、评论、收藏 | 本地演示身份与示例内容，不是多用户服务 |
| 我的 | 资料编辑、植物/帖子/收藏入口、成就、设备说明、提醒开关、隐私与文本备份、异常数据确认恢复 | 不提供真实登录、设备绑定、云同步 |

环境监测、天气地域、智能硬件三个需求维度保留说明及服务边界，不冒充真实接入。九大业务模块仍保留，真实后端、硬件控制、成长视频和高级装扮不在本轮实现范围。

验收原则：实际构建、测试和生产 dist 验证分别记录；部署成功与线上交互验收分开。未通过预览线上验收前，不覆盖原 V3 正式站点。

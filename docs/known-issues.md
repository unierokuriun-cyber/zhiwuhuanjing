# 已知问题与上线门槛

1. 当前云环境未允许植伴托管域名，原 V3 域名仍返回 CONNECT 403。现有工具只可读取网络状态，没有白名单写入操作。需要用户在当前 Codex 云环境的网络设置中添加站点域名并保存/应用到运行环境；不能通过临时改代理解决。
2. V3 已部署、V4/V5 独立预览已部署，但历次线上浏览器交互验收均未完成。不能把平台 succeeded 当作线上验收通过；本轮未重复部署旧版本。
4. AI/识别/天气/硬件/多人社区/真实认证均未接入；所有相关页面保留演示边界。设备管理仅说明未连接状态，不模拟真实绑定。
5. Chromium 自动化覆盖不能等同于 iOS Safari、实体手机软键盘或真实硬件验收；这些仍需真机手动检查。
6. 文本备份不包含 IndexedDB 图片，没有自动导入或跨域迁移。清除浏览器数据仍会丢失本地内容；不应将当前版本当作生产级云数据服务。
7. 没有独立组件测试框架；业务逻辑、状态和 UI 测试通过 Playwright 执行，不另声称组件单测覆盖。
8. Lighthouse 为本地单次模拟移动测量，非正式线上指标；私有预览 robots 禁止抓取，SEO 不作为本轮发布验收目标。
